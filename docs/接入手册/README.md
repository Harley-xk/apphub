# 应用接入手册

> 面向接入 apphub 应用管理平台的应用方开发者：按需选择能力、按册接入，互不强耦合。
> 各能力可独立接入——仅用发版更新、仅用会员认证、或认证 + 订阅付费组合，均开箱即用。

## 1. 选册导航

| 接入需求 | 阅读手册 | 需要的凭证 | 是否需要请求签名 |
| --- | --- | --- | --- |
| 应用发版 + 客户端检查更新 | [更新检测接入手册](更新检测接入手册.md) | appKey | 否（救生通道，零密钥接入） |
| 发版自动化（agent / CI 一键打包上传发布） | [发版 Skill](../../skills/apphub-release/SKILL.md)（设计见 [发版 Skill 设计](../应用管理平台/发版Skill设计.md)） | appKey + 发版账号 | 平台开启签名时需要（skill 自动处理） |
| 用户注册 / 登录 / 身份校验 | [会员认证接入手册](会员认证接入手册.md) | appKey + appSecret | 是（HMAC 请求签名） |
| 付费订阅（在线支付） | [订阅支付接入手册](订阅支付接入手册.md)（前置：会员认证） | appKey + appSecret | 是（同上） |

订阅链路依赖会员身份（下单需会员令牌），因此接入订阅前须先完成会员认证接入；更新检测与两者完全无关。发版 Skill 走平台管理端接口（应用开发侧项目的 agent 安装 `skills/apphub-release/` 即可完成打包 → 上传 → 发布 → 验证全流程闭环），与更新检测手册面向的客户端接入互补。

### 1.1 安装或更新发版技能

- **未安装 / 旧版没有自更新能力**：只需把 `https://appcenter.witice.top/api/skill/apphub-release` 交给 Claude 等 agent（详见 [技能安装与更新](技能安装与更新.md)）；该接口由平台托管，不依赖技能包，无需平台账号
- **已安装且可自更新**：在应用工程执行 `node .claude/skills/apphub-release/scripts/apphub.mjs self-update`（加 `--check` 只检查）
- **版本检查（公开接口）**：`https://appcenter.witice.top/api/skill/apphub-release/manifest`

## 2. 通用约定（三册共用）

### 2.1 服务地址

平台线上环境基址为 **`https://appcenter.witice.top`**，全部开放接口挂在 `/api` 前缀下：

```text
https://appcenter.witice.top/api/open/app/version/check      ← 更新检测
https://appcenter.witice.top/api/open/member/**              ← 会员认证
https://appcenter.witice.top/api/open/subscription/**        ← 订阅
```

> 基址不含 `/api` 后缀（配置 `baseUrl` 时填 `https://appcenter.witice.top`）。私有化部署或联调环境使用平台方另行提供的基址，下文示例统一按线上基址书写。

### 2.2 统一响应结构

所有业务接口返回 JSON 包裹结构，**以 `code` 字段判结果、不以 HTTP 状态码单独判**：

```json
{ "code": 0, "message": "ok", "data": { } }
```

| 场景 | HTTP 状态码 | code | 说明 |
| --- | --- | --- | --- |
| 成功 | 200 | `0` | POST 创建成功同样归一为 200 |
| 业务失败 | 400 | 九位分段码 | 如 `400300001`（账号或密码错误），语义见各册错误码表 |
| 签名校验失败 / 令牌无效 | 401 | 分段码或 `401` | 不区分具体失败环节，防止探测 |
| 请求过于频繁 | 429 | `429` | 触发限流（见 2.4） |

### 2.3 错误码分段规则

九位数字 = 模块段 3 位 + 子域段 3 位 + 序号 3 位，数值首位即出错的能力域：

| 数值形态 | 模块 | 示例 |
| --- | --- | --- |
| `300xxxxxx` | 应用与更新 | `300100002` AppKey 无效 |
| `400xxxxxx` | 会员认证 | `400300001` 账号或密码错误 |
| `500xxxxxx` | 订阅与支付 | `500100002` 订阅计划已下架 |

### 2.4 限流

全部开放接口按 **AppKey + IP** 滑动窗口限流，默认 **60 次 / 分钟**；公开客户端（appSecret 编译进客户端二进制分发的形态）阈值减半 **30 次 / 分钟**。超限返回 HTTP 429。接入方应做好 429 的退避重试，不要在收到 429 后立即重发。

### 2.5 时钟要求

请求签名含时间戳校验（±5 分钟窗口），接入方设备须开启 NTP 时钟同步；离线或时钟漂移过大的设备将无法通过需要签名的接口（更新检测不受影响）。
