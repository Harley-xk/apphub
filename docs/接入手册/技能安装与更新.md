# apphub-release 技能安装与更新（冷启动）

适用于：应用工程**尚未安装**本技能，或已安装的旧版本**没有 `self-update` 能力**。已安装且可自更新的工程直接执行 `node scripts/apphub.mjs self-update --check` 即可，无需本页。

本页由平台托管，**不依赖技能包**——用户工程里没有任何 apphub 技能时也能直接访问。

**只需要交给 agent 一个地址：**

```text
https://appcenter.witice.top/api/skill/apphub-release
```

该地址直接返回本安装说明（Markdown）；agent 读取后按步骤下载安装器即可完成安装或更新。

以下为平台公开接口（免登录、免签名，无需发版账号）：

| 资源 | 地址 |
| --- | --- |
| 版本清单（版本 + 每文件 sha256） | `https://appcenter.witice.top/api/skill/apphub-release/manifest` |
| 安装 / 更新器 | `https://appcenter.witice.top/api/skill/apphub-release/install.mjs` |
| 本说明 | `https://appcenter.witice.top/api/skill/apphub-release` |

## 给用户的一句话

> 把这个地址交给 Claude，让它按说明安装 / 更新 apphub 发版技能：
> `https://appcenter.witice.top/api/skill/apphub-release`

## agent 执行步骤

1. 读取版本清单，确认远端版本：
   ```bash
   curl -fsSL https://appcenter.witice.top/api/skill/apphub-release/manifest
   ```
2. 下载安装器到临时目录（不要直接在技能目录内执行下载的脚本）：
   ```bash
   curl -fsSL https://appcenter.witice.top/api/skill/apphub-release/install.mjs -o /tmp/apphub-install.mjs
   ```
3. 先检查（未安装 / 有更新 / 已最新）：
   ```bash
   node /tmp/apphub-install.mjs --check --target .claude/skills/apphub-release
   ```
4. 安装或更新（默认项目级；用户级用 `--target ~/.claude/skills/apphub-release`）：
   ```bash
   node /tmp/apphub-install.mjs --target .claude/skills/apphub-release
   ```
5. 验证并汇报：
   ```bash
   cat .claude/skills/apphub-release/VERSION
   node .claude/skills/apphub-release/scripts/apphub.mjs --help
   ```
   告知用户：新会话或下次调用技能时加载最新指令；首次使用还需按 `SKILL.md` 的「首次接入」生成 `.apphub-release.json`。

## 私有化部署

所有命令追加 `--base-url https://你的-apphub-域名`（不含 `/api`）。安装后的 `self-update` 会优先读应用工程 `.apphub-release.json` 的 `baseUrl`，也可用 `--base-url` 显式指定。

## 安全边界

- 只从平台基址下载；安装器按 manifest 的 sha256 逐文件校验，不匹配即中止且不写入
- 只写入 `SKILL.md` / `VERSION` / `scripts/`，不触碰应用工程根目录的 `.apphub-release.json`
- 更新失败自动回滚；首次安装先落 staging 目录，完成后整体原子改名
