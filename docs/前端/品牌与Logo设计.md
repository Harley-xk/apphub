# 品牌与 Logo 设计

> 状态：已定稿（2026-10-20 第二轮，母品牌变体「三花聚心」取代第一轮浮卡层叠）。本文档是 apphub 品牌 logo 的唯一设计依据，图形改动先改本文档再改代码。

## 1. 背景与母品牌血缘

apphub 是「智汇冰芯 WITICE」体系下的应用管理平台（上线域名 appcenter.witice.top 与母品牌同源）。母品牌 logo（`web/public/logo-dark.svg`）的图形语言：

- **六边形冰晶框**：pointy-top 正六边形（几何中心 (40, 36)、顶点距中心 29）
- **六向分叉雪花枝臂**：三条 path 互转 30° / 90° / 150° 生成，水平方向留给代码括号
- **代码括号**：`{ }` 展现为两条折线（深底版亮白）
- **冰蓝渐变**：#9FD0F0 → #38A3E8

apphub 品牌 logo 为母品牌的**业务变体**：保留六边形冰晶框与六向分叉雪花基因，去掉代码括号（平台不强调代码属性），并将单雪花拆为三朵环绕中心枢纽——「多应用环绕 hub 汇聚」即平台业务语义。

品牌名（UI 层面）：**应用管理平台**（apphub），仅出现在用户可见的 UI 层面（产品名、标题、logo、文案）；框架代码前缀不做品牌化（见 [rules/branding.md](../../rules/branding.md)）。

## 2. 演化与比选

两轮评审（2026-10-20，主张编号制）。

**第一轮**（无母品牌参照，四方向）：

| 主张 | 方向 | 结论 |
| --- | --- | --- |
| L1 | 浮卡层叠：三层阶梯圆角卡 + 前卡白色枢纽点 | 当轮定稿，后被第二轮取代 |
| L2 | 中枢汇聚：中心主色方块 + 四角卫星连线 | 落选：16px 下连线糊化 |
| L3 | 字母 A + 版本点 | 落选：与平台视觉语言关联弱 |
| L4 | 六边形矩阵 + 中心枢纽 | 落选：六边形俗套，与卡片语言脱节 |

**第二轮**（以母品牌 logo 为基础做业务变体）：

| 主张 | 方向 | 结论 |
| --- | --- | --- |
| V1 | 冰晶浮卡：母品牌框 + 臂完整保留，括号换双卡错位 | 落选：品牌框架与业务元素拥挤 |
| V2 | 括号护卡：母品牌改动最小，括号间放应用卡 | 落选：血统最浓但业务语义含蓄 |
| V3 | 六边舱位：仅留六边形框，中心三层阶梯卡 | 用户选中作为演化基底（自定加雪花内核） |
| S6 / S3 | 雪花群：中心大雪花 + 环绕小雪花节点（六 / 三节点） | 落选：小节点 16px 不可辨，稿间差异弱 |
| S4 | **三花聚心（留隙版）：三朵中雪花品字靠边，环绕中心枢纽** | **定稿** |

**S4 演化过程**：用户指示「三朵中雪花各贴一边品字均布、中心交叠约 1/3」→ 交叠版实测 18 条带分叉的臂在中心编织糊化 → 评审定为「交叠改留隙」：朝心臂尖停在距中心 4 处，枢纽点独立居中，以向心留隙表达汇聚。

**S4 定稿理由**：

- **三朵中雪花 = 接入应用**（appcenter 多应用纳管），品字各贴一条边
- **中心枢纽点 = hub**（统一认证 / 订阅中枢），三花向心环绕、留隙即汇聚张力
- **血缘纯正**：六边形冰晶框 + 六向分叉雪花与母品牌一眼可辨（同坐标系、同色系）
- **小尺寸稳**：三花 + 留隙结构在 30px 顶栏可辨；16px favicon 固定用单雪花简化变体

## 3. 图形规格（定稿 S4）

基于 `viewBox="0 0 80 80"`（与母品牌同坐标系，几何中心 (40, 36)）：

| 图元 | 规格 | 描边 / 填充 |
| --- | --- | --- |
| 六边形冰晶框 | `M40 7 L65 21.5 L65 50.5 L40 65 L15 50.5 L15 21.5 Z` | 渐变描边 3.5，框内冰蓝 tint 底 |
| 中雪花 × 3 | 等臂 R8、六臂全分叉、线宽 2.2 圆头；花心距中心 12，品字靠边 | 渐变描边 |
| 枢纽点 | circle(40, 36, r 2.8) | 渐变实心 |

三朵雪花位姿（花心 = 中心 + 12 × 方向单位向量；自转使朝心臂指向六边形中心）：

| 位置 | 方向 φ | 花心坐标 | 自转 θ |
| --- | --- | --- | --- |
| 左 | 180° | (28, 36) | 90° |
| 右下 | 300° | (46, 44.39) | −30° |
| 右上 | 60° | (46, 25.61) | −150° |

单朵雪花臂型（局部坐标：原点 = 花心，−y = 朝心方向；臂参数——内端 3、外端 8、分叉起 4.5、叉端 7.5、叉横距 1.9；一条臂型互转 0° / 60° / 120° 生成六臂）：

```svg
<path d="M0 -8 L0 -3 M0 -4.5 L-1.9 -7.5 M0 -4.5 L1.9 -7.5 M0 8 L0 3 M0 4.5 L-1.9 7.5 M0 4.5 L1.9 7.5"/>
```

关键几何约束（改动校验用）：

- 朝心臂尖距中心 = 12 − 8 = **4**（留隙，不伸过中心）
- 臂外端距中心 = 12 + 8 = 20，距边内沿约 3.35（贴边不撞框）
- 相邻花心距 = 2 × 12 × sin60° ≈ 20.8 > 2R = 16（三花互不相交）

组装骨架（色彩见 §4）：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 80 80" fill="none">
  <defs>
    <linearGradient id="g" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0" stop-color="渐变浅端（§4）"/>
      <stop offset="1" stop-color="渐变深端（§4）"/>
    </linearGradient>
  </defs>
  <path d="M40 7 L65 21.5 L65 50.5 L40 65 L15 50.5 L15 21.5 Z"
    stroke="url(#g)" stroke-width="3.5" fill="tint（§4）"/>
  <g stroke="url(#g)" stroke-width="2.2" stroke-linecap="round" stroke-linejoin="round">
    <g transform="translate(28 36) rotate(90)">六臂 × 3 path（上表臂型）</g>
    <g transform="translate(46 44.39) rotate(-30)">同上</g>
    <g transform="translate(46 25.61) rotate(-150)">同上</g>
  </g>
  <circle cx="40" cy="36" r="2.8" fill="url(#g)"/>
</svg>
```

### favicon 简化变体（16px 专用）

三花结构在 16px 下退化为噪点，favicon 固定用**单雪花简化变体**：六边形框 + 中心单雪花 + 枢纽点，同框同色。单雪花臂型（世界坐标，臂外端半径 19、内端 6、分叉起 15、叉端 18.6、叉横距 3.6，三条互转 30° / 90° / 150°）：

```svg
<path d="M40 17 L40 30 M40 21 L36.4 17.4 M40 21 L43.6 17.4 M40 55 L40 42 M40 51 L36.4 54.6 M40 51 L43.6 54.6"/>
```

枢纽点 r 3.2、雪花线宽 3（单花下加粗补偿小图形密度）。

## 4. 色彩规格（token 对应）

**品牌架构决策**：logo 冰蓝承母品牌，平台 UI 主色保持青碧（`--apphub-color-primary`，见 [布局与风格设计](布局与风格设计.md)）——logo 与 UI 主色不同源，母品牌统一视觉基因、子产品 UI 各自独立。因此 logo 使用专用冰蓝 token：

| 用途 | 浅色 | 暗色 | token |
| --- | --- | --- | --- |
| 渐变浅端 | `#9FD0F0` | `#C9E6F8` | `--apphub-logo-ice-a`（**新增**） |
| 渐变深端 | `#38A3E8` | `#5CB4EC` | `--apphub-logo-ice-b`（**新增**） |
| 框内 tint 底 | `rgba(86, 182, 240, .08)` | `rgba(86, 182, 240, .12)` | `--apphub-logo-tint`（**新增**） |

暗色适配：渐变两端整体提亮一档、tint 加浓，与母品牌深底版策略一致。

第一轮的 `--apphub-logo-layer-mid`（青碧中间层）随 L1 浮卡层叠一并移除。

## 5. 使用场景

| 场景 | 尺寸 | 变体 | 实现方式 | 出处 |
| --- | --- | --- | --- | --- |
| 顶栏品牌区（`layout:logo` 槽位默认组件） | 30px | 三花聚心 | 公共组件 `BrandMark` 内嵌 SVG，渐变 / 描边 / 填充走 CSS 变量（token 活引用，明暗自动翻转） | `web/src/components/BrandMark/index.vue` + `web/src/layouts/default/defaults/DefaultLogo.vue` |
| 登录页品牌区 | 44px | 三花聚心 | 同上 | `web/src/views/login/index.vue` |
| 浏览器 favicon | 16px+ | 单雪花简化 | 静态 SVG 文件，内嵌 `prefers-color-scheme` 双套 | `web/public/favicon.svg`，`web/index.html` 引用 |
| 外部引用（文档 / 物料） | 任意 | 按场景 | UI 场景取 BrandMark 图形；favicon 场景取静态文件 | — |

完整标 = 图形标 + 字标「应用管理平台」（顶栏 16px / 600 字重，登录页为标题），字标样式随场景，不单独设计字标图形。

## 6. 实现约定

1. **单一图形事实源**：图形几何只定义于本文档 §3；`BrandMark` 组件与 `favicon.svg` 均按本文档生成，改图形先改文档
2. **组件内不硬编码色值**：渐变 stop-color / stroke / tint 一律 `var(--apphub-logo-*)`；静态文件（favicon）例外，写死双套色值
3. **favicon 不依赖 CSS 变量**：经 `@media (prefers-color-scheme: dark)` 切换（现代浏览器全支持；老浏览器回落浅色套，无 ico 兜底需求）
4. **图形组件尺寸外置**：`BrandMark` 根 svg 不定宽高（100% 填充容器），使用方经 class 指定尺寸（顶栏 `apphub-logo-mark` 30px、登录页 `login-logo` 44px，e2e 断言依赖这两个类名）
